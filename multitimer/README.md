# multitimer

並列 3 タイマー (パスタ + 茹で卵 + お茶を同時に作る用)。

## できること

3 スロットそれぞれに名前と秒数を設定し、独立にカウントダウン。グラスには 3 枠の残時間が一覧表示され、選択中のスロットには `▶` が付く。

## 操作

| 入力 | 動作 |
|---|---|
| グラス タップ | 選択スロットを次へ |
| グラス ダブルタップ | 選択スロットの Start / Stop トグル |
| ブラウザ Start/Stop selected | 同上 |
| ブラウザ Reset selected | 選択スロットを初期秒数に戻す |
| ブラウザ Next slot | 選択スロットを次へ |
| ブラウザ Set (各スロット) | 名前と秒数を保存し、そのスロットを停止 |

## 状態

- 保存キー: `multitimer.v1`
- スロット数は 3 固定 (画面が狭いため。増やしたければ `slots` 初期化を編集)

## 起動

```powershell
xr multitimer
```
