# hiit

20 秒 on / 10 秒 off × 8 ラウンドのタバタ式インターバルタイマー。

## できること

`GO 18s / Round 3/8` のように現在フェーズと残秒、ラウンド進捗を表示。Round 8 を消化すると `DONE` で停止。

## 操作

| 入力 | 動作 |
|---|---|
| グラス タップ | 開始 / 一時停止 / 再開 (DONE 後は最初から) |
| グラス ダブルタップ | 完全リセット |
| ブラウザ Start/Reset | 同上 |

## 状態

- `ON_SEC = 20`, `OFF_SEC = 10`, `ROUNDS = 8` (`src/main.ts` 冒頭で変更可)
- 永続化なし (起動ごとにリセット)

## 起動

```powershell
xr hiit
```
