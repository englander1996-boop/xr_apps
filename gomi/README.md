# gomi

今日のゴミの日。

## できること

曜日ごとのゴミ分類 (燃える / プラ / 缶ビン …) をブラウザで設定すると、グラスに「今日 (Mon): 燃える / 明日: プラ」のように表示。30 分ごとに自動更新。

## 操作

| 入力 | 動作 |
|---|---|
| グラス操作 | なし (常時表示) |
| ブラウザ 各曜日テキスト入力 | 分類名を入力。空欄なら「(no trash)」表示 |
| ブラウザ Save schedule | 全曜日を保存して即反映 |

## 状態

- 保存キー: `gomi.v1` (`{ schedule: string[7] }`, 日曜始まり)

## 起動

```powershell
xr gomi
```
