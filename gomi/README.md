# gomi

今日のゴミの日。

## できること

曜日ごとのゴミ分類 (燃える / プラ / 缶ビン …) をブラウザで設定すると、グラスに「Today (Mon): 燃える / Next (Tue): プラ」のように表示。30 分ごとに自動更新。タップで先の日 (`+2d`, `+3d`...) も覗ける。

## 操作

| 入力 | 動作 |
|---|---|
| グラス タップ | 表示日を 1 日進める (Today → Tomorrow → +2d → ... → +6d → Today) |
| グラス ダブルタップ | Today にリセット |
| ブラウザ 各曜日テキスト入力 | 分類名を入力。空欄なら「(no trash)」表示。**文字入力はグラス不可なのでブラウザ専用** |
| ブラウザ Save schedule | 全曜日を保存して即反映 |

## 状態

- 保存キー: `gomi.v1` (`{ schedule: string[7] }`, 日曜始まり)

## 起動

```powershell
xr gomi
```
