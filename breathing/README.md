# breathing

ボックスブリージング (4-4-4-4) ガイド。

## できること

吸う 4s → 止める 4s → 吐く 4s → 止める 4s のサイクルを永遠に回す。グラスには現在フェーズと残秒、進捗バー、完了サイクル数を表示。

## 操作

| 入力 | 動作 |
|---|---|
| グラス タップ | 開始 / 一時停止 |
| グラス ダブルタップ | 完全リセット |
| ブラウザ Start/Pause | 同上 |
| ブラウザ Reset | リセット |

## カスタマイズ

`PHASES` 配列 (`src/main.ts` 冒頭) を編集すれば 4-7-8 呼吸法などにも対応可。

## 起動

```powershell
xr breathing
```
