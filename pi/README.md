# pi

円周率の桁を 1 桁ずつ増やしていく暗記サポート。

## できること

最初は `3.141` (5 桁) からスタート。タップで 1 桁ずつ追加表示、ダブルで 1 桁減らせる。約 500 桁分を内蔵 (`src/main.ts` の `PI` 定数)。現在の表示桁数は localStorage に保存。

## 操作

| 入力 | 動作 |
|---|---|
| グラス タップ | +1 桁 |
| グラス ダブルタップ | -1 桁 (最低 2 桁) |
| ブラウザ Show next digit | +1 桁 |
| ブラウザ Hide last | -1 桁 |
| ブラウザ Reset to 5 | 5 桁に戻す |

## 起動

```powershell
xr pi
```
