# coffeelog

コーヒー杯数のロガー。

## できること

タップで「今日 1 杯飲んだ」を記録。今日の杯数と直近 7 日の平均を表示。日付ごとにキーを分けて保存しているので「カフェイン取りすぎてるか」を平均値で確認できる。

## 操作

| 入力 | 動作 |
|---|---|
| グラス タップ | +1 杯 |
| グラス ダブルタップ | Undo (1 杯減らす) |
| ブラウザ +1 cup / Undo | 同上 |

## 状態

- 保存キー: `coffeelog.v1` (`{ "YYYY-MM-DD": count, ... }`)
- 古いデータは消さない (本気で 7 日以上溯りたければ JSON 直接見る)

## 起動

```powershell
xr coffeelog
```
