# horoscope

日替わり星占い (オフライン・決定論的)。

## できること

12 星座 × 15 種類のメッセージから、星座と日付のハッシュで「今日のメッセージ」を決定論的に選ぶ。同じ日に何度開いても同じ結果なので「占い」として一貫性がある。

## 操作

| 入力 | 動作 |
|---|---|
| グラス タップ | 星座を次へ循環 |
| ブラウザ Cycle sign | 同上 |

## 状態

- 保存キー: `horoscope.sign.v1` (現在の星座)
- 日付が変わるとメッセージも自動で変わる

## カスタマイズ

`MESSAGES` 配列を編集すれば自分の好みの占いメッセージ集に差し替え可能。

## 起動

```powershell
xr horoscope
```
