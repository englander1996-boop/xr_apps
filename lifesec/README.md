# lifesec

自分の DOB (誕生日) からの経過時間カウンタ。

## できること

DOB をブラウザで設定すると、経過時間を秒/分/時/日/年の好きな単位で 1 秒ごとに更新表示。`1,234,567,890 sec since 1990-01-01` みたいに地味に味わいがある。

## 操作

| 入力 | 動作 |
|---|---|
| グラス タップ | 単位を sec → min → hour → day → year で循環 |
| グラス ダブルタップ | sec にリセット |
| ブラウザ Cycle unit | タップと同じ |
| ブラウザ Save DOB | 入力した日付を保存 (**生年月日は日付入力 UI 必須のためブラウザ専用 / 一度設定すれば変えないはず**) |

## 状態

- 保存キー: `lifesec.dob.v1` (ISO 日付文字列)

## 起動

```powershell
xr lifesec
```
