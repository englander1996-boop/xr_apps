# stopwatch

ラップ機能つきストップウォッチ。

## できること

1/100 秒精度で計測。タップで Start / Lap、ダブルで Stop & Reset。最新ラップタイムと累計ラップ数をグラスに表示。

## 操作

| 入力 | 動作 |
|---|---|
| グラス タップ | (停止中) 開始 / (動作中) ラップ記録 |
| グラス ダブルタップ | 停止 & 全リセット |
| ブラウザ Start/Lap | 同上 |
| ブラウザ Stop & Reset | 停止 & 全リセット |

## メモ

ブラウザ側は `requestAnimationFrame` で滑らかに表示するが、グラスは ~500ms 間引きで描画 (G2 への描画コール頻度を抑えるため)。

## 起動

```powershell
xr stopwatch
```
