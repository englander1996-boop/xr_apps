# simon

記憶ゲーム Simon の単タップ版。

## できること

S (シングルタップ) と D (ダブルタップ) のランダムな列が順に表示される (Watch)。表示が終わったら同じ列をタップ/ダブルタップで再現 (Repeat)。正解するとラウンドが進み、列が 1 つ伸びる。ミスするとロスト。

## 操作

| 入力 | 動作 |
|---|---|
| グラス タップ | (Watch 中) 無視 / (Repeat 中) S を入力 |
| グラス ダブルタップ | (Repeat 中) D を入力 |
| ブラウザ Start round | 新ラウンドを開始 |
| ブラウザ Input S / D | 同上 (ブラウザでもプレイ可) |

## 起動

```powershell
xr simon
```
