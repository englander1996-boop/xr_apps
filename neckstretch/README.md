# neckstretch

首ストレッチガイド (6 動作 × 15 秒)。

## できること

左に倒す → 中央 → 右に倒す → 中央 → 上を向く → 下を向く、を 15 秒ずつ。デスクワークの合間にどうぞ。終了時 `Done!`。

## 操作

| 入力 | 動作 |
|---|---|
| グラス タップ | 開始 (動作中は無視) |
| グラス ダブルタップ | リセット |
| ブラウザ Start / Reset | 同上 |

## カスタマイズ

`MOVES` / `PER_SEC` 定数を編集すれば任意のストレッチルーチンを作れる。

## 起動

```powershell
xr neckstretch
```
