# gitcheat

Git の救命コマンド 18 個 (reflog / bisect / stash / cherry-pick / force-with-lease 等)。

## できること

`git restore --staged FILE / unstage but keep changes` みたいなコマンドと意味を 1 枚ずつ表示。

## 操作

| 入力 | 動作 |
|---|---|
| グラス タップ | 次へ |
| グラス ダブルタップ | ランダムジャンプ |
| ブラウザ Next / Random | 同上 |

## カスタマイズ

`TIPS` 配列を編集すれば自分用にできる。

## 起動

```powershell
xr gitcheat
```
