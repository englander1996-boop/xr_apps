# quote

名言ローテーション 16 件 (Jobs / Einstein / Knuth / Torvalds / 日本のことわざ等)。

## できること

タップで次の名言、ダブルでランダムジャンプ。

## 操作

| 入力 | 動作 |
|---|---|
| グラス タップ | 次へ |
| グラス ダブルタップ | ランダム |
| ブラウザ Next / Random | 同上 |

## カスタマイズ

`QUOTES` 配列 (`[quote, author][]`) を編集。自分のお気に入りリストにできる。

## 起動

```powershell
xr quote
```
