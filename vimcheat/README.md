# vimcheat

Vim のよく忘れるショートカット 20 個をローテーション表示。

## できること

`ciw / change inner word` みたいに「キー / 意味」を 1 枚ずつ表示。手が止まったときにグラスをタップしてヒントを得る用途。

## 操作

| 入力 | 動作 |
|---|---|
| グラス タップ | 次へ |
| グラス ダブルタップ | ランダムジャンプ |
| ブラウザ Next / Random | 同上 |

## カスタマイズ

`TIPS` 配列を編集 (`[command, description][]`)。自分のチートシートに置き換えるのもアリ。

## 起動

```powershell
xr vimcheat
```
