# reaction

反応時間 (リアクションタイム) 測定。

## できること

スタート後 1〜4 秒のランダム待機 → `*** GO ***` 表示でタップ、ms 単位で反応速度を計測。早押しすると `Too early!` でペナルティ。ベスト記録と直近 3 回の履歴を表示。

## 操作

| 入力 | 動作 |
|---|---|
| グラス タップ | (idle/jumped/result) スタート / (wait) 早押しペナルティ / (go) 計測完了 |
| グラス ダブルタップ | 即スタート |
| ブラウザ Start | スタート |

## 起動

```powershell
xr reaction
```
