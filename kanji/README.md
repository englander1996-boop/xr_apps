# kanji

難読漢字 20 個 (薔薇 / 檸檬 / 憂鬱 / 麒麟 / 朧月夜 等)。

## できること

`薔薇 / ？` の状態で表示 → タップで `ばら — rose` (読み + 意味) を表示 → もう一度タップで次の漢字。

## 操作

| 入力 | 動作 |
|---|---|
| グラス タップ | 答え表示 / 次へ |
| グラス ダブルタップ | 答えを見ずにスキップ |
| ブラウザ Reveal/Next / Skip | 同上 |

## カスタマイズ

`KANJI` 配列 (`[kanji, reading, meaning][]`) を編集。和英ペアでなく中国語にもできる。

## 起動

```powershell
xr kanji
```
