# meditation

5 / 10 / 15 / 20 分の瞑想タイマー。

## できること

プリセット時間を選んで開始。残時間を 1 秒ごとに更新表示し、終了時に `*** DONE ***`。1 つの timer インスタンスのみ (Pomodoro より単純な「ただ座って計る」用途)。

## 操作

| 入力 | 動作 |
|---|---|
| グラス タップ | プリセット切替 (5→10→15→20→5) |
| グラス ダブルタップ | Start / Stop トグル |
| ブラウザ Cycle preset | プリセット切替 |
| ブラウザ Start / Stop | 同上 |

## 起動

```powershell
xr meditation
```
