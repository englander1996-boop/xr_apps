# minesweeper

4×4 マインスイーパー (地雷 3 個、フラグ機能なし)。

## 操作

| 入力 | 動作 |
|---|---|
| グラス scroll-up | カーソル ↑ (折返し) |
| グラス scroll-down | カーソル ↓ (折返し) |
| グラス タップ | カーソル → (右端で次行へ折返し) |
| グラス ダブルタップ | 現在セルを開く |
| ブラウザ ↑↓←→ ボタン | カーソル移動 (左右もネイティブ操作可) |
| ブラウザ Reveal | 開く |
| ブラウザ New game | 新規ゲーム |

## ルール

- 16 セルのうち地雷 3 個 = 残り 13 セルを全部開ければ勝ち
- 地雷を開いた瞬間負け、全地雷位置を `*` で公開
- **連鎖開示**: 周囲 0 個のセルを開くと隣接セルを再帰的に自動で開く (BFS で実装)
- **フラグ機能なし** (G2 はジェスチャ 4 種しか無いため省略)

## セル表示

| 文字 | 意味 |
|---|---|
| `·` | 未開示 |
| `1`-`8` | 開示済み、周囲にこの数だけ地雷あり |
| (空白) | 開示済み、周囲に地雷なし |
| `*` | 地雷 (ゲームオーバー時のみ公開) |
| `[X]` | カーソル位置 |

例:
```
[·][ ][1][·]
[·][1][2][·]
[·][·][·][1]
[·][·][·][·]
```

## 実装メモ


再帰だとスタックオーバーフローが心配だが、BFS なら 16 セル程度なら何の問題もない。
