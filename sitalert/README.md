# sitalert

座りすぎ警告アラート。

## できること

最後に立った時刻から経過時間が閾値 (30/45/60/90/120 分) を超えると、グラスに `** STAND UP **` 表示。立ち上がったらタップでリセット (= 「立った」宣言)。今日の累計起立回数も記録。

## 操作

| 入力 | 動作 |
|---|---|
| グラス タップ | 立ったことを記録 (タイマーリセット + カウント +1) |
| グラス ダブルタップ | インターバルを 30→45→60→90→120 分で循環 |
| ブラウザ I stood up | 同上 |
| ブラウザ Cycle interval | 同上 |

## 状態

- 保存キー: `sitalert.v1` (`{ intervalMin, lastStoodAt, standCount }`)

## 起動

```powershell
xr sitalert
```
