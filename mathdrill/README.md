# mathdrill

四則演算の暗算ドリル。

## できること

`12 × 7 = ?` のように出題。頭で計算してからタップで答え表示 → 合っていたか自分でジャッジしてもう一度タップで次の問題。スコア (回答数 / 出題数) を集計。

数の範囲は素直なやつ (2 桁掛け算は ×9 まで、割り算は割り切れるもののみ等)。

## 操作

| 入力 | 動作 |
|---|---|
| グラス タップ | 答え表示 → 次の問題 (スコア +1) |
| グラス ダブルタップ | 答えを見ずにスキップ (スコアは増えない) |
| ブラウザ Reveal/Next | 同上 |
| ブラウザ Skip | スキップ |

## 起動

```powershell
xr mathdrill
```
