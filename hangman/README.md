# hangman

英単語 1 文字ずつ当てるクラシック Hangman。

## 操作

| 入力 | 動作 |
|---|---|
| グラス scroll-up | カーソル ◀ (前の文字へ) |
| グラス scroll-down | カーソル ▶ (次の文字へ) |
| グラス タップ | 現在カーソル位置の文字を確定 |
| グラス ダブルタップ | 新規ゲーム |
| ブラウザ ボタン | 同上 |

## ルール

- 40 語の単語リストからランダムに 1 つ選ばれる
- ミス 6 回で負け、全文字当てれば勝ち
- 既に試した文字は中点 (·) 表示で重複防止
- アルファベット表示でカーソル位置は `[X]` で囲まれる

## 表示

```
Word:  _ E _ L O
Misses: B, K
Cursor: G
ABCDEF[G]HIJ·LM·O····UV·XYZ
Tries: 3/6
```

`A`〜`Z` の表示で：
- `[X]` = カーソル
- `·` = 既に試してミスした文字
- 大文字のまま = 未試行 or 既にヒット (区別したいなら拡張ポイント)

## カスタマイズ

`src/main.ts` 冒頭の `WORDS` 配列に追加するだけ。大文字で書く。

## 起動

```powershell
xr hangman
```
