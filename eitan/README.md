# eitan

英単語フラッシュカード 40 語 (中〜上級の動詞・形容詞中心)。

## できること

`ubiquitous / ？` の状態で表示 → タップで和訳 (どこにでもある) 表示 → もう一度タップで次の単語。

## 操作

| 入力 | 動作 |
|---|---|
| グラス タップ | 答え表示 / 次へ |
| グラス ダブルタップ | 答えを見ずにスキップ |
| ブラウザ Reveal/Next / Skip | 同上 |

## カスタマイズ

`WORDS` 配列 (`[word, meaning][]`) を編集。Anki デッキの export を流し込むのも手。

## 起動

```powershell
xr eitan
```
