# nato

NATO フォネティックアルファベット (A=Alpha … Z=Zulu) のフラッシュカード。

## できること

26 文字を 1 つずつ表示。タップで次へ。`Reveal` トグルで答えを隠せるので暗記練習にも。

## 操作

| 入力 | 動作 |
|---|---|
| グラス タップ | 次の文字 |
| グラス ダブルタップ | 答え表示のトグル |
| ブラウザ Next | 次へ |
| ブラウザ Reveal | 答え表示トグル |
| ブラウザ Random | ランダムジャンプ + 答え隠す (テスト用) |

## 起動

```powershell
xr nato
```
