# periodic

周期表 全 118 元素 (原子番号 + 元素記号 + 英語名)。

## できること

`1  H / Hydrogen` のように 1 元素ずつ表示。タップで次、ダブルでランダムジャンプ。

## 操作

| 入力 | 動作 |
|---|---|
| グラス タップ | 次の元素 |
| グラス ダブルタップ | ランダム |
| ブラウザ Next / Random | 同上 |

## メモ

データは `src/main.ts` の `ELEMENTS` 配列 (`[symbol, name][]`)。和名にしたい場合はここを編集。

## 起動

```powershell
xr periodic
```
