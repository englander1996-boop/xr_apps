# lastsince

「最終 X からの経過時間」記録ツール。

## できること

事前に登録した複数項目 (デフォ: Coffee / Water / Stretch) のうち 1 つを選んで、最後に「やった」タイムスタンプからの経過を表示。タップで項目切替、ダブルで「いま実行」を記録。

## 操作

| 入力 | 動作 |
|---|---|
| グラス タップ | 次の項目へ |
| グラス ダブルタップ | 選択中の項目を「いま実行」(タイマーリセット) |
| ブラウザ Mark now | 同上 |
| ブラウザ Next item | 同上 |

## 状態

- 保存キー: `lastsince.v1` (`[{ name, at: timestamp }, ...]`)
- 項目を増減したいときは `src/main.ts` の初期値配列を編集する (今は UI から追加 / 削除はできない、必要なら拡張ポイント)

## 起動

```powershell
xr lastsince
```
