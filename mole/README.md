# mole

1 ボタン版モグラ叩き。

## できること

スタートすると「... wait ...」表示でランダム待機 → 突然 `*** MOLE ***` が出る。MOLE 中にタップすればスコア +1、待機中にタップしたり、MOLE を 1.2 秒以内に叩けないとミス。反応 + 我慢の両方が試される。

## 操作

| 入力 | 動作 |
|---|---|
| グラス タップ | (wait) ミス / (mole) ヒット |
| グラス ダブルタップ | リスタート |
| ブラウザ Start round | リスタート |
| ブラウザ Whack | タップと同じ |

## 起動

```powershell
xr mole
```
