# textadv

ごく短いテキストアドベンチャー (暗い洞窟で目覚める)。

## できること

各シーンに 2 択 (A / B) があって、タップ = A、ダブル = B で物語を進める。エンディングは数種類。`start` に戻れば何度でも遊べる。

## 操作

| 入力 | 動作 |
|---|---|
| グラス タップ | 選択肢 A |
| グラス ダブルタップ | 選択肢 B |
| ブラウザ A / B | 同上 (現在ノードの A/B ラベルが表示される) |

## カスタマイズ

ストーリーは `src/main.ts` の `STORY` オブジェクトで定義。`Node = { text, a: { label, to }, b: { label, to } }` でノードを足せばすぐ拡張できる。

## 起動

```powershell
xr textadv
```
