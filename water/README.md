# water

水分補給ロガー。

## できること

今日 1 杯飲むごとにタップ。今日の累計と目標 (デフォ 8 杯) に対する進捗バー、最後の sip からの経過時間を表示。日付が変わるとカウントは自動リセット。

## 操作

| 入力 | 動作 |
|---|---|
| グラス タップ | +1 杯 |
| グラス ダブルタップ | Undo (1 杯減らす) |
| ブラウザ +1 cup / Undo | 同上 |

## 状態

- 保存キー: `water.v1` (`{ date, count, lastAt, goal }`)
- 目標値を変えたいときは保存値を編集するか、`goal` の初期値 `8` を `src/main.ts` で変更

## 起動

```powershell
xr water
```
