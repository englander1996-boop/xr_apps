# wordle

5 文字単語を 6 回以内に当てる Wordle。

## 操作

カーソルが 6 位置 (スロット 0-4 + SUBMIT) を行き来する。

| 入力 | 動作 |
|---|---|
| グラス scroll-up | スロット ◀ |
| グラス scroll-down | スロット ▶ (最後を超えると SUBMIT) |
| グラス タップ | スロット上: 文字 +1 / SUBMIT 上: 提出 |
| グラス ダブルタップ | スロット上: 文字 -1 / SUBMIT 上: 新ゲーム |
| ブラウザ ボタン | Submit / New game / Letter ± / Slot ± |

## フィードバック表記

色がないので記号で：

- `X` = その位置にその文字が正しくある (本家の緑)
- `.` = 文字は答えに含まれるが位置違い (本家の黄)
- `_` = 答えに含まれない (本家のグレー)

例: `APPLE → X._._` だと A が完全一致、P が位置違い、L が含まず、E が位置違い。

## マーキングの罠 (実装メモ)

`PEACH` を当てるとき `EERIE` を入力すると、本家 Wordle では「最初の E は present、2 番目の E は absent」になる。**同じ文字が複数あるときの処理を 2 周ループにする** ことで本家挙動を再現してる:

```ts
// 1周目: correct を確定して answerArr から消費
// 2周目: 残った文字で present を判定
```

## 単語データ

`WORDS` 配列に 100 語。出題も判定もこの中から (辞書バリデーションなし)。増やしたいときは追加するだけ。

## 起動

```powershell
xr wordle
```
