# counter

タリーカウンタ (タップで +1)。

## できること

在庫数え、人数カウント、回数カウント等の汎用カウンタ。ラベルをブラウザで設定でき、値は localStorage に保存される。

## 操作

| 入力 | 動作 |
|---|---|
| グラス タップ | +1 |
| グラス ダブルタップ | 0 にリセット |
| ブラウザ +1 / -1 / Reset | 同上 |
| ブラウザ Label 入力 | ラベルを変更して保存 (change イベントで即反映) |

## 状態

- 保存キー: `counter.v1` (`{ label, n }`)

## 起動

```powershell
xr counter
```
