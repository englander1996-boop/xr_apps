# wareki

西暦 ↔ 和暦変換器。

## できること

任意の西暦年に対応する和暦 (令和 / 平成 / 昭和 / 大正 / 明治) を表示。元年は「元年」と表示。タップで年を動かして連続確認できる。

## 操作

| 入力 | 動作 |
|---|---|
| グラス タップ | 年 +1 |
| グラス ダブルタップ | 年 -1 |
| ブラウザ Now | 今年に戻す |
| ブラウザ Set year | 入力欄の年を反映 (**任意年へジャンプはグラスから数字入力不可なのでブラウザ専用**) |

## 範囲

明治 (1868) 以降のみ対応。それ以前は `(out of range)`。

## 起動

```powershell
xr wareki
```
