# numguess

あなたが思い浮かべた 1〜100 の数字を、アプリが二分探索で当てる。

## できること

「Is it 50?」と聞いてくる。あなたが頭の中で思った数より大きければタップ、小さければダブルタップ。最少 7 回程度で必ず当てる。

## 操作

| 入力 | 動作 |
|---|---|
| グラス タップ | 「もっと大きい」(Higher) |
| グラス ダブルタップ | 「もっと小さい」(Lower) |
| ブラウザ Higher / Lower | 同上 |
| ブラウザ Reset | 範囲を 1-100 に戻して再開 |

正解にたどり着くと `Got it: 42! Tries: 6` 表示 → 次のタップで自動リセット。

## 起動

```powershell
xr numguess
```
